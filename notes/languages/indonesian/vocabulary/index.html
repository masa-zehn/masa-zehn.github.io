VOCABULARY

気になった単語

綴りが偶然似ている単語と、実際に同じ語源を持つ単語を分けて記録しています。

FALSE FRIENDS似ているけれど別の語源

WORD / 001 · FAUX AMI

istri

名詞妻

配偶者である女性を表す。

01由来・構造

サンスクリット語の strī（女性・妻）に由来する借用語。

02似ている外国語

  • Spanishhistoria歴史・物語
  • Frenchhistoire歴史・物語
MY
NOTE

自分のコメント

ラテン系言語の「歴史」に当たる語とよく似ているが、語源も意味も別。

WORD / 002 · FAUX AMI

laut

名詞海

海や大きな水域を表す。

01由来・構造

マレー・インドネシア語に古くからある語。ドイツ語からの借用ではない。

02似ている外国語

  • Germanlautうるさい・音が大きい
MY
NOTE

自分のコメント

綴りはドイツ語とまったく同じなのに、意味は「海」。

SHARED ROOTS同じ語源・借用関係のある単語

WORD / 003 · ARABIC ROOT

dunia

名詞世界・現世

人が生きている世界を表す。

01由来・構造

アラビア語の dunyā に由来する借用語。単語全体で借用されており、インドネシア語の接辞は付いていない。

02同じ語源の言葉

  • Turkishdünya世界・地球
MY
NOTE

自分のコメント

トルコ語とは母音が違うだけで、形も意味もかなり近い。

WORD / 004 · ARABIC ROOT

hasil

名詞結果・成果

行動から得られた結果や産物。

01由来・構造

アラビア語の ḥāṣil に由来する借用語。インドネシア語では接辞を付けずに名詞として使える。

02同じ語源の言葉

  • Turkishhasıl生じたもの・成果
MY
NOTE

自分のコメント

初めて見た時に、「あれーなんかトルコ語にこんなのあったような...」と思い、調べてみたら同語源だった。

WORD / 005 · EUROPEAN LOAN

televisi

名詞テレビ

映像と音声を受信する装置や放送。

01由来・構造

オランダ語 televisie を経て入った語。さらに遡ると「遠く」を表す tele- と「見る」に関わる語から成る。

02同じ語源の言葉

  • Englishtelevisionテレビ・テレビ放送
MY
NOTE

自分のコメント

英語とほぼ同じなので、初見でも意味を推測しやすい。英語の-tionがインドネシア語では-siになることが多いらしい。

WORD / 006 · EUROPEAN LOAN

nomor

名詞数字・番号

順番や識別のために付ける番号。

01由来・構造

オランダ語 nummer に由来する借用語。さらに遡るとラテン語の「数」に関わる語へつながる。

02同じ語源の言葉

  • GermanNummer番号
MY
NOTE

自分のコメント

ドイツ語の Nummer と母音は違うが、音も意味もよく似ている。

WORD / 007 · EUROPEAN LOAN

turis

名詞観光客

旅行先を訪れる人。

01由来・構造

オランダ語 toerist など、ヨーロッパの「tour」に関わる語から入った借用語。

02同じ語源の言葉

  • Englishtourist観光客
MY
NOTE

自分のコメント

英語の綴りから余分な文字を落としたように見え、覚えやすい。

WORD / 008 · ARABIC ROOT

hayat

名詞命・生命

生きていることや生命。

01由来・構造

アラビア語の ḥayāh（生命）に由来する借用語。接辞には分けない。

02同じ語源の言葉

  • Turkishhayat人生・生命
MY
NOTE

自分のコメント

これまたトルコ語と似ているインドネシア語の単語。

WORD / 009 · EUROPEAN LOAN

staf

名詞スタッフ・職員

組織で働く人々。

01由来・構造

ヨーロッパの言語から入った借用語。語末の子音を一つにした、インドネシア語らしい綴りになっている。

02同じ語源の言葉

  • Englishstaff職員・スタッフ
MY
NOTE

自分のコメント

英語の staff とほぼ同じで、語末の f が一つだけになる。

WORD / 010 · INTERNATIONALISM

internasional

形容詞国際的な

複数の国に関係すること。

01由来・構造

ラテン語系の要素を持つ国際語彙。インドネシア語では英語の -tional に当たる部分が -sional になる。

02同じ語源の言葉

  • Englishinternational国際的な
MY
NOTE

自分のコメント

英語との規則的な綴りの違いが分かると、似た単語も見つけやすそう。

WORD / 011 · LATIN ROOT

fasilitas

名詞施設・設備

活動を行うために用意された場所や設備。

01由来・構造

ラテン語 facilitas を起点とするヨーロッパ系の借用語。単語全体が取り入れられている。

02同じ語源の言葉

  • Englishfacility施設・設備・能力
MY
NOTE

自分のコメント

英語とは語尾が違うが、語幹と意味はほぼ同じ。

WORD / 012 · DUTCH LOAN

halte

名詞停留所

バスなどが停車する場所。

01由来・構造

オランダ語 halte から、そのままに近い形で入った借用語。

02同じ語源の言葉

  • Dutchhalte停留所
  • GermanHaltestelle停留所
MY
NOTE

自分のコメント

オランダ語とは綴りも意味も同じ。ドイツ語の Haltestelle にも似た要素が見える。

WORD / 013 · DUTCH LOAN

apotek

名詞薬局

薬を調剤・販売する場所。

01由来・構造

オランダ語 apotheek から入った借用語。さらに遡ると古代ギリシャ語の「保管場所」に由来する。

02同じ語源の言葉

  • Dutchapotheek薬局
  • GermanApotheke薬局
MY
NOTE

自分のコメント

オランダ語やドイツ語と比べると、発音に合わせて短く整理されたような綴り。
