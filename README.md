# masa-zehn.github.io
GitHub Pagesを使って、プロダクト・学習ノート・文章を公開するためのリポジトリ。

## ディレクトリ構成

- `products/`: 作成したツールやアプリ
- `notes/`: 学んだことをまとめた記事
- `journals/`: エッセイ、日記、雑記
- `assets/`: サイト全体で共有するスタイルや画像

言語ノートは `notes/languages/` にまとめ、各言語の `index.html` を概要と子記事へのハブとして使用します。
